# Clínica CITTO - Project Documentation

Este projeto foi importado do **Stitch** e implementado seguindo o sistema de design "The Clinical Editorial".

## 🌿 Creative North Star
**"The Clinical Editorial"**
O objetivo é transformar ambientes clínicos em santuários digitais, equilibrando a precisão médica com o acolhimento humano.

## 🎨 Design Tokens
- **Cores Principais:**
  - Folha de Oliveira (`#506C38`)
  - Taupe Terroso (`#6F6350`)
  - Off-White (`#FFFCF7`)
- **Tipografia:**
  - Headlines: **Newsreader** (Serif)
  - Body: **Manrope** (Sans-Serif)

## 📁 Estrutura de Arquivos
- `index.html`: Estrutura principal da homepage.
- `style.css`: Implementação completa dos tokens de design (layout, cores, tipografia).
- `hero_clinic.webp`: Imagem de cabeçalho gerada via AI para representar o conceito de "Santuário Clínico".
